# 🌓 ThemeFlow — React Theme Context App

A responsive React application demonstrating global theme state management (`Light` / `Dark` mode) using the **React Context API** with automatic **`localStorage` persistence**.

## ✨ Key Features
* **Global Theme Context:** Toggle themes across components with zero prop-drilling.
* **Persistent State:** Saves user preference automatically in browser `localStorage`.
* **System Color Detection:** Respects system-level `prefers-color-scheme` settings.
* **Modern UI:** Responsive dashboard design with dynamic CSS custom properties.

## 🛠️ Tech Stack
* **Framework:** React + Vite
* **Styling:** CSS Variables (Custom Properties)
* **Storage:** Web Storage API (`localStorage`)
